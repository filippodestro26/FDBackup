# FDBackup v0.1.0-beta

Prima release pubblica di FDBackup.

## In evidenza

- backup tradizionale e versionato Full/Incrementale/Differenziale;
- ripristino completo e selettivo con ricostruzione delle catene;
- tombstone per rappresentare le eliminazioni tra versioni;
- verifica SHA-256 e verifica post-backup opzionale;
- sincronizzazione Update e Mirror;
- scheduler indipendente dalla GUI, System Tray e avvio automatico Windows;
- filtri per estensioni/pattern, dimensione e attributi;
- Activity persistente, notifiche Windows e gestione esplicita degli errori;
- dashboard, report e strumenti di retention;
- 361 test automatici superati sulla baseline Windows/Python 3.14.

## Stato

Questa release è classificata **Beta**. È destinata alla valutazione e all'evoluzione del progetto e non sostituisce una strategia di backup professionale già validata per dati critici.

Consultare il README per requisiti, limitazioni e istruzioni di esecuzione.
